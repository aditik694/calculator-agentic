# Calculator Build Comparison

## Build 1 — Vibe Coding

### Development Approach
The calculator was implemented directly using an AI coding agent from a natural-language prompt.

### Outcome
- Four arithmetic operations implemented.
- Pytest tests generated.
- Division-by-zero behavior handled.
- Tests executed successfully.

### Observations
- Development was fast.
- Minimal upfront planning was required.
- The AI made implementation decisions automatically.
- The resulting structure depended heavily on the prompt and coding agent.
- Repeatability needs to be evaluated by rebuilding the same requirement.
